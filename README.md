# Настольное приложение «Заметки»

## 1. Описание проекта
«Заметки» — приложение для ведения личного дневника и управления текстовыми записями. Предназначено для создания, хранения, просмотра, редактирования и удаления заметок.

**Основные возможности:**
* создание и редактирование заметок;
* просмотр списка сохранённых записей;
* удаление заметок с подтверждением действия;
* поиск заметок по содержимому;
* фильтрация и сортировка заметок по дате создания.

**Технологии:**
* Язык программирования: **C#**;
* Пользовательский интерфейс: **WPF**;
* Платформа: **.NET**;
* База данных: **Microsoft SQL Server**;
* Работа с данными: **Entity Framework**.

## 3. Установка и запуск
Для запуска приложения необходимо:
1. Установить **Microsoft SQL Server**.
2. Выполнить SQL-скрипт для создания базы данных `Notes` и соответствующей таблицы.
3. Открыть файл решения `Notes.sln` в **Microsoft Visual Studio**.
4. В файле `App.config` указать имя своего экземпляра SQL Server в строке подключения.
5. Собрать проект и запустить приложение клавишей `F5`.

## 4. Использование
После запуска приложение открывает главное окно со списком всех сохранённых заметок. Пользователь может просматривать записи, искать их по содержимому и изменять отображение списка с помощью фильтра по дате.

Для создания заметки необходимо нажать кнопку «+», заполнить поля названия и описания, а затем нажать «Создать».

Для редактирования записи следует дважды щёлкнуть по ней в списке, внести необходимые изменения и нажать «Сохранить».

Для удаления заметки необходимо выделить её в списке, нажать кнопку «Удалить» и подтвердить действие в появившемся окне.

## 5. Структура проекта
В данном разделе размещён скриншот структуры проекта, где наглядно отображены основные каталоги и файлы приложения.

**Описание основных компонентов:**
* `entities/` — папка с классами сущностей, сгенерированными для работы с таблицами базы данных;
* `MainWindow.xaml` / `MainWindow.xaml.cs` — главное окно приложения со списком заметок, поиском и сортировкой;
* `EditNotesWindow.xaml` / `EditNotesWindow.xaml.cs` — модальное окно для создания новой или редактирования существующей заметки;
* `App.config` — конфигурационный файл со строкой подключения к БД;
* `App.xaml` / `App.xaml.cs` — точка входа в приложение и его ресурсы.

## 6. База данных
Приложение использует реляционную базу данных `Notes`. Взаимодействие построено через Entity Framework. Данные сохраняются в базе данных и автоматически загружаются при открытии приложения. Создание структуры базы данных выполняется с помощью SQL-скрипта, входящего в состав проекта.

**Основные сущности:**
* `Notes` — таблица для хранения заметок (содержит поля `id`, `title`, `description`, `created_at`).
